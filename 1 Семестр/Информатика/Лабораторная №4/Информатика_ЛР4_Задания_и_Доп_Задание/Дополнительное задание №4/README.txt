Дополнительное задание 4: простой замер времени (вариант 87).

1. Открой папку lab4_dop4_simple в VS Code.
2. Если PyYAML ещё не установлен: python -m pip install PyYAML
3. Запусти: python dop4.py

Скрипт выведет суммарное время 100 вызовов каждого способа.
Чтение и запись файлов НЕ учитываются во времени — измеряются функции.
Основное задание измеряет только парсинг, поэтому его время напрямую
не сопоставимо с тремя полными конвертациями. Для отчёта сравни полные
способы доп. 1, 2, 3; укажи эту оговорку.
