# University Materials

Репозиторий для хранения и систематизации учебных материалов, собранных в процессе обучения в университете.

Здесь находятся лабораторные и практические работы, исходный код программ, конспекты, учебные пособия и другие материалы по изучаемым дисциплинам.

Все материалы организованы по семестрам и предметам для удобной навигации и дальнейшего использования.
